3. 뉴런과 활성값

이 영상에서 뉴런은 0에서 1 사이 숫자 하나를 담는 것. 그 숫자가 활성값(activation)이고, 값이 클수록 뉴런이 밝게 켜진 것으로 그림.

  • 입력층: 28×28 = 784개. 각 뉴런이 픽셀 하나의 밝기를 담음 (검정 0, 흰색 1)
  • 출력층: 10개. 각 뉴런이 "이 이미지가 그 숫자일 정도"를 담음
  • 은닉층: 그 사이. 숫자를 어떻게 알아보는지는 일단 커다란 물음표

정확히는 뉴런이 담는 값이 입력 이미지마다 달라지므로, 뉴런은 앞 층의 출력을 받아 0~1 숫자를 내는 함수로 보는 것이 맞음 (15:17).

4. 층을 쌓는 이유

사람이 숫자를 알아볼 때는 부분 모양을 조합함.

  • 9 = 위쪽 고리 + 오른쪽 세로선
  • 8 = 위쪽 고리 + 아래쪽 고리
  • 4 = 직선 세 개

이상적으로는 마지막 은닉층의 뉴런 하나하나가 이런 부분 모양 하나씩을 맡고, 그 앞 은닉층은 고리나 직선을 이루는 짧은 선분을 맡기를 기대함. 그러면 이미지가 들어왔을 때 선분 8~10개 → 위쪽 고리와 세로선 → 숫자 9 순서로 켜짐.

이렇게 단계별로 추상화하는 구조는 다른 이미지 인식이나 음성 인식(소리 → 음절 → 단어 → 문장)에도 쓸모가 있음.

기대일 뿐실제로 학습된 신경망이 이렇게 동작하는지는 영상도 답을 미룸. 학습 방법을 본 뒤 다음 편에서 다시 다룸.

5. 가중치와 가중합

두 번째 층의 뉴런 하나가 "이 영역에 선분이 있는가"를 알아내게 하려면 어떤 다이얼이 필요할까. 답은 입력층과 이어진 연결선마다 숫자(가중치) 하나.

w₁a₁ + w₂a₂ + w₃a₃ + ⋯ + w₇₈₄a₇₈₄

가중치 784개를 입력 이미지와 같은 28×28 격자로 그려 보면 이해가 쉬움.

초록은 양수, 빨강은 음수 가중치이고 색이 진할수록 절댓값이 큼.

6. 시그모이드와 편향

시그모이드: 가중합을 0~1로 압축

가중합은 어떤 실수든 나올 수 있지만, 활성값은 0~1 사이여야 함. 그래서 실수 전체를 0~1 구간으로 눌러 주는 함수를 씌움. 대표적인 것이 시그모이드(로지스틱 곡선).

σ(x) = 1 / (1 + e−x)

아주 작은 음수는 0 근처로, 아주 큰 양수는 1 근처로 가고, 0 근처에서 빠르게 증가함. 따라서 활성값은 "가중합이 얼마나 양수인가"를 나타내는 값.

편향: 켜지는 기준을 옮기는 숫자

가중합이 0보다 클 때가 아니라 10보다 클 때만 뉴런이 켜지게 하고 싶다면, 시그모이드에 넣기 전에 −10 같은 숫자를 더함. 이 숫자가 편향(bias).

a = σ(w₁a₁ + w₂a₂ + ⋯ + w₇₈₄a₇₈₄ + b)
  • 가중치: 이 뉴런이 어떤 픽셀 패턴을 찾는지
  • 편향: 가중합이 얼마나 커야 뉴런이 의미 있게 켜지는지

7. 매개변수 13,002개

뉴런 하나에 가중치 784개와 편향 1개. 같은 층의 모든 뉴런이 앞 층의 모든 뉴런과 연결되므로 전체 개수는 다음과 같음.

연결가중치편향
입력 784 → 은닉 16784 × 16 = 12,54416
은닉 16 → 은닉 1616 × 16 = 25616
은닉 16 → 출력 1016 × 10 = 16010
합계12,96042

합쳐서 13,002개. 영상에서는 "거의 정확히 13,000개"라고 말함. 신경망이 어떻게 동작할지를 바꾸는 다이얼이 이만큼 있다는 뜻이고, 학습이란 컴퓨터가 이 숫자들의 좋은 값을 찾게 하는 것.

8. 행렬로 한 줄에 쓰기

뉴런마다 가중합을 따로 쓰면 식이 너무 길어짐. 그래서 이렇게 정리함.

  • 한 층의 활성값을 세로 벡터 a⁽⁰⁾로
  • 가중치를 행렬 W로. 행 하나가 다음 층 뉴런 하나로 들어오는 연결 전체
  • 편향을 벡터 b로
  • 시그모이드는 결과 벡터의 원소 하나하나에 적용
a⁽¹⁾ = σ( W a⁽⁰⁾ + b )

행렬·벡터 곱의 결과에서 원소 하나가 곧 뉴런 하나의 가중합. 이렇게 쓰면 식이 짧아지고, 라이브러리가 행렬곱을 아주 잘 최적화해 두었기 때문에 코드도 간단하고 빨라짐.

NumPy로 옮기면

학습하지 않은 무작위 가중치라 답은 의미가 없고, 구조와 매개변수 개수만 확인하는 코드.

import numpy as np

rng = np.random.default_rng(0)
sizes = [784, 16, 16, 10]
weights = [rng.normal(0, 1, (n_out, n_in)) for n_in, n_out in zip(sizes[:-1], sizes[1:])]
biases = [rng.normal(0, 1, n_out) for n_out in sizes[1:]]

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

a = rng.uniform(0, 1, 784)          # 28×28 이미지 대신 무작위 밝기
for W, b in zip(weights, biases):
    a = sigmoid(W @ a + b)          # a⁽ˡ⁺¹⁾ = σ(W a⁽ˡ⁾ + b)

print(a.argmax())                   # 가장 밝은 출력 뉴런 = 신경망의 답
print(sum(W.size + b.size for W, b in zip(weights, biases)))  # 13002

결국 신경망 전체가 함수 하나. 숫자 784개를 받아 10개를 내고, 매개변수 13,002개와 행렬곱·시그모이드의 반복으로 이루어짐. 영상은 이 함수가 이 정도로 복잡해 보이는 것이 오히려 다행이라고 말함. 더 단순했다면 숫자를 알아보리라고 기대하기 어려웠을 테니.

9. 시그모이드 대신 ReLU

영상 끝의 리샤 리 인터뷰. 초기 신경망은 뉴런이 꺼짐/켜짐 두 상태라는 생물학적 비유 때문에 시그모이드를 썼지만, 요즘은 거의 쓰지 않음.

ReLU(a) = max(0, a)
  • 시그모이드로는 학습이 매우 어려운 경우가 있었음
  • ReLU를 써 보니 아주 깊은 신경망에서도 잘 학습됨
  • 기준을 넘으면 켜지고 못 넘으면 꺼진다는 생물학적 비유를 더 단순하게 만든 것
